# Toisteisuus, toiminnallisuus, korjailu
Agentti refaktoroi koodin oikein näppärästi, kuten voi olettaa pienessä skaalassa ja suppealla määrällä testitapauksia. Täräytin ohjeiksi:
```
The job is simple. Refactor tests,  move repetetive setup to "setUp" function. Confirm tests pass afterwards. Do not change the logic of tests.
```
Toimeksianto on kirjoitettu lyhyesti ja ytimekkäästi. Agentille kerrotaan täsmälleen mitä tehdä lisäkehoituksineen jonkin ympäripyöreän *"refaktoroi nää"* tai *"refaktoroi koodi"* promptin sijasta. Tuossa on noin niinkun mainittu:
* Refaktoroidaan nimen omaan testejä
* Nimen omaan setUp funktioon
* Tarkista että testit toimivat
* Älä muuta testien logiikkaa

Mitä tulee toiminnallisuuteen ja korjailuun, mihinkään näistä ansoista ei langettu koska se mitä pyydettiin oli mietitty hyvin ennen pyytämistä, ei heikkouksia!
